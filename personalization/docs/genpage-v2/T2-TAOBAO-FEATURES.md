# T2 순차 모델에 통계 곁채널을 넣으면 이기는지 (측정 전에 적는다, 2026-09-30, #447)

## 왜

T1(#438)에서 순차 모델(G)은 순위 모델(R)에 졌다. 시험 날 묶음 GAUC 는 G 0.5512, R 0.5760 이었다. G 는 광고 전날 클릭률 하나로 매긴 선(0.5518)과 같았다.

G 에는 R 이 쓰는 두 종류의 수치가 입력으로 없었다.

- 전날까지 전체 통계: 광고 · 카테고리 · 브랜드 · 캠페인별 노출 · 클릭 수와 평활 클릭률
- 고객 이력 카운트: 같은 광고 · 카테고리 · 브랜드 · 캠페인에서 노출 · 클릭 수, 마지막 노출 · 클릭 뒤 지난 시간

쿠아이쇼우 OneRec 은 이런 통계 · 범주 특징을 아이템 토큰과 별도 경로로 인코더에 넣는다(arXiv 2506.13695).

여기서 묻는 것은 두 가지다.

1. G 에 R 의 수치 특징을 곁채널로 넣은 G+F 가 R 을 이기는가
2. 곁채널이 G 를 얼마나 올리는가(G+F − G)

## 무엇을 그대로 두는가

- 데이터 · 분할 · 입력 규칙 · 지표(묶음 GAUC) · 짝 부트스트랩은 T1(`T1-TAOBAO.md`)과 같다
- R 은 T1 에서 고른 leaves 31 의 시험 날 예측을 그대로 쓴다. G 도 T1 의 d128_l2 시험 날 예측을 그대로 쓴다
- G+F 의 순차 모델 부분은 T1 에서 고른 d128_l2 설정 · 학습 방식(AdamW lr 1e-3, 배치 256명, 최대 3 에폭, 검증 묶음 GAUC 로 최선 에폭, 시드 7)을 그대로 쓴다. 설정을 새로 고르지 않는다

## G+F: 곁채널

- 입력: R 의 특징 중 수치 27개(고객 이력 15개 + 전날까지 전체 통계 12개). 범주 특징(고객 속성 · 맥락 · 카테고리 · 브랜드 · 가격 구간)은 G 가 이미 임베딩으로 받으므로 넣지 않는다
- 변환: 카운트는 log1p, 클릭률은 그대로, "지난 시간"은 log1p(시간), 없으면(한 번도 없음) 별도 표시 칸을 1 로 두고 값은 0. 학습 분할 평균 · 표준편차로 표준화한다
- 구조: 특징 벡터 → Linear(27 + 표시 칸 수 → d) → GELU → Linear(d → d) 를 질의 토큰에 더한다. 이력 토큰에는 넣지 않는다
- 값은 R 의 특징 코드(`taobao.features`)가 만든 것을 그대로 쓴다. 두 모델이 같은 수치를 본다

## 판정

1. G+F 를 학습 분할로 학습하고 검증 날로 에폭을 고른다(검증 묶음 GAUC 를 적는다)
2. 시험 날에서 한 번 잰다
3. 같은 고객 짝 부트스트랩(2,000회, 시드 7)으로 (G+F) − R 의 묶음 GAUC 차이 95% 구간
   - 0 보다 위: **"곁채널을 단 순차 모델이 이겼다"**
   - 0 을 포함: **"비겼다"**
   - 0 보다 아래: **"졌다"**
4. 같은 방법으로 (G+F) − G 의 구간. 0 보다 위면 "곁채널이 순차 모델을 올렸다"
5. 결과가 어느 쪽이든 그대로 적는다. 시험 날은 판정 2 에서 한 번만 본다

## 알고 적는 한계

- G+F 는 설정 기회가 하나(T1 에서 고른 것)이고 R 은 셋이었다. G+F 에 불리한 쪽이다
- G+F 가 이겨도 R 의 특징을 그대로 받은 것이라 "순차 모델만으로" 이긴 것은 아니다. 묻는 것은 "노출열을 읽는 모델 + 통계"가 "통계 + 트리"를 넘는지다
