# T3 — 학습한 행 통계 머리는 손으로 고른 λ 를 넘지 못했다 (#463)

**GenPage 행 선택에 행 통계를 받는 머리를 학습해 붙였더니 검증 페이지 nDCG 가 0.0386 이었다.** 손으로 고른 λ=4 로 순위 모델 행 점수를 더한 H'(4)(0.0542)와 규칙 줄 구성(0.0529)에 모두 크게 못 미쳤다. 측정 전에 정한 판정 3 에 따라 홀드아웃은 재지 않고 "학습한 머리가 손으로 고른 λ 를 넘지 못했다"로 적는다.

## 무엇을 했나

D5 에서 이긴 결합은 GenPage 행 로그 확률에 순위 모델 행 점수(고객의 허용 행 안에서 표준화)를 손으로 고른 λ=4 배로 더했다. T3 는 λ 대신 작은 머리(행 통계 6개 → 16 → 1)를 학습해 그 출력을 더한다.

- 행 통계: 그 행 상위 8개 순위 점수의 합 · 최댓값 · 평균, 상위 200개 안 상품 수, 다시 사기 행 여부, 고객 안 행 점수 합 순위
- 학습: GenPage 는 고정. r − 7 주 구매 고객 70,356명의 행 선택 단계 132,442개. 정답은 GenPage 사전학습과 같은 방식으로 다음 주 구매를 행으로 묶은 페이지의 행 순서를 허용 행으로 제한한 것
- 누설 방지: 학습 주 순위 점수는 r − 21 로 학습하고 r − 14 로 조기 종료(180 반복)한 뒤 두 주로 다시 학습한 모델로 매겼다. r − 7 은 학습 · 조기 종료 어디에도 쓰지 않았다. 고객 75,822명을 채점했다

## 왜 못 넘었나(추정)

1. **학습 목표가 판정 지표와 달랐다.** 머리는 "다음 주에 산 상품을 행으로 묶은 페이지의 행 순서"를 흉내 내도록 학습했다. 그 정답 페이지는 산 상품 수가 많은 행부터 놓는다(사전학습 방식). 판정 지표인 페이지 nDCG 는 행 안을 순위 모델 순서로 채운 뒤 위쪽 행에 정답이 있는지를 본다. 손으로 고른 λ 는 페이지 nDCG 로 직접 골랐고, 머리는 다른 목표를 따라갔다
2. **다시 사기 행을 충분히 올리지 못했다.** 재구매 적중이 0.0361 로 GenPage 만(0.0236)보다는 높지만 H'(4) · 규칙(0.0668)의 절반이다. 정답 페이지에서 다시 사기 행은 고객이 실제로 다시 산 경우에만 나온다. 다음 주에 다시 사는 고객은 일부라 머리가 다시 사기 행에 큰 값을 줄 근거가 학습 데이터에 적었다
3. **GenPage 를 고정했다.** 머리는 GenPage 의 행 로그 확률에 더해지기만 한다. GenPage 가 다시 사기 행을 거의 안 고르는 쪽으로 학습돼 있어(G-row' 879명 / 1만), 작은 머리가 뒤집기에 손실 기울기가 작았다

## 판정에 쓰지 않은 것

- 홀드아웃은 판정 3 에 따라 재지 않았다
- 머리를 페이지 nDCG 로 직접 학습하거나(목표 정렬) GenPage 를 함께 미세 조정하는 변형은 측정 전 설계에 없어 돌리지 않았다
