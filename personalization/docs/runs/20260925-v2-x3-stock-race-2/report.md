## 판정

1. **모델 출력을 그대로 믿으면 응답의 80% 이상에 품절 상품이 섞인다.** 모델은 재고를 모른다(교체 가능한 의존성, 재고는 order 의 소유). 모델 출력은 business state 가 아니다
2. **가장 이른 확인(PRE)이 거르는 방식 중 가장 나쁘다.** 확인한 뒤 생성하는 동안(약 200 ms) 팔린 것을 못 잡는다(0.23~0.25%). 요청마다 품절 목록 조회(6.4 ms)도 든다
3. **지금 방식(POST)이 이미 99.9% 를 거른다.** 조립과 응답 사이의 짧은 창에서만 0.06~0.12% 가 새어 나간다. 재고가 카드 조회에 실려 와 별도 조회 비용이 없다
4. **응답 직전 재확인(POST_FINAL)은 그 창을 더 좁히고(10/s 에서 0%) 비용은 요청당 0.2 ms 이하다.** 지연 차이는 측정 오차 안이다
5. 남는 극소수는 결제 승인 시점의 재고 차감(ADR-003)이 최종으로 막는다. **추천 단계는 약간의 stale 을 허용하고 구매 단계에서만 강하게 보장한다**는 경계가 숫자로 확인됐다
