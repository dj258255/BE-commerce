## 검증 (실기동)

- `GET /api/v1/products?category=ladieswear` → **39,737건**, 이름이 한글/영문 정상 표시
- `GET /api/v1/products?q=Dress` → **8,144건**
- `GET /api/v1/products?featured=true` → H&M 상품(추천)
- **주문 E2E**: H&M 상품(2p Claw × 2 = 2,000원) → 주문 생성 → 승인 200 → **PAID / DONE**

## 정직한 한계

- **가격은 합성이다.** 순위·비교에는 쓸 수 있지만, 원장·정산의 KRW 금액처럼 다루면 안 된다.
- **재고도 합성이다.** 실제 재고가 아니므로 제약 실험(M4)에서 이 사실을 함께 적는다.
- **이미지는 일부만 있다(19.4%).** Kaggle 인증이 없어 전체를 못 받았다 — 자세한 경로와 커버리지는
  `hm-images.md`에 적었다. 나머지는 화면이 그라디언트로 폴백한다.
- 레거시 데모 상품은 V55에서 은퇴했다. 상품 1~3은 k6·통합 테스트가 써서 남기되, 탐색 표면(카테고리·
  '신상품')에서는 빠지게 했다 — picsum 랜덤 사진을 달고 상품처럼 보이던 것이 스토어프론트를 가짜로 만들었다.
