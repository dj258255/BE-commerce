## 카테고리 — 2단계 (V56)

**대분류**(`index_group_name` 5종) — `category_code`

| code | 이름 | 상품 수 |
|---|---|---:|
| `ladieswear` | 여성복 | 39,737 |
| `kids` | 아동복 | 34,711 |
| `divided` | Divided | 15,149 |
| `menswear` | 남성복 | 12,553 |
| `sport` | 스포츠 | 3,392 |

**중분류**(`garment_group_name` 21종) — `subcategory_code`, **72개**

실측에서 대분류(성별/라인)와 중분류(상품 종류)가 **직교**한다는 것이 드러났다 — 중분류 21종 중
**2종만** 한 대분류에 속한다(니트는 여성복·남성복·아동복·Divided에 다 있다). 그래서 트리로 접으면
노드가 **(대분류 × 중분류) 조합**이 되고, 5×21=105 중 **실제 존재하는 72개**만 노드로 만든다.

| 대분류 | 중분류 (상위 3개) |
|---|---|
| `ladieswear` | 저지 팬시 6,163 · 액세서리 4,999 · 언더웨어·나이트웨어 4,513 (총 18개) |
| `kids` | 저지 팬시 9,103 · 저지 베이직 4,193 · 액세서리 3,293 (총 17개) |
| `divided` | 드레스 2,267 · 저지 팬시 2,128 · 액세서리 1,458 (총 15개) |
| `menswear` | 저지 팬시 2,077 · 셔츠 1,434 · 액세서리 1,388 (총 16개) |
| `sport` | 저지 팬시 1,974 · 기타 788 · 액세서리 381 (총 5개) |

이름은 **번역이 확실한 것만 한국어**로 하고, 확실하지 않으면 H&M 원문을 그대로 썼다
(`Dressed`, `Woven/Jersey/Knitted mix Baby`). 원문은 `categories.source_name`에 남긴다 — 우리가 지은
이름의 근거가 추적돼야 한다. `Special Offers`→특가, `Unknown`→기타도 같은 규칙이다.

**부모 카운트 == 자식 합**을 적재 전에 스크립트가 assert하고, 적재 후 실DB에서 다시 확인했다(5/5 일치).
중분류가 대분류를 빠짐없이 나누므로 성립하는 등식이다.

## 검증 (실기동)

- `GET /api/v1/categories` → **5건**(대분류만, 기존 동작 유지)
- `GET /api/v1/categories?tree=true` → **77건**, 부모 다음에 그 자식들이 오는 순서
- 부모 카운트 == 자식 합 → 실DB에서 **5/5 일치**
- `GET /api/v1/products?category=ladieswear` → **39,737건** (회귀 없음)
- `?category=ladieswear.knitwear` → **2,917건** · `ladieswear.jersey-fancy` → **6,163건**
  · `menswear.shirts` → **1,434건** · `sport.trousers` → **1건** (모두 중분류 실측값과 일치)
- 화면: `category.html?code=ladieswear.knitwear` → 브레드크럼 `홈 / 여성복 / 니트`, 사이드바 2단계,
  중분류 칩 18개. 홈 칩은 대분류 5개 그대로
- **주문 E2E**: H&M 상품(2p Claw × 2 = 2,000원) → 주문 생성 → 승인 200 → **PAID / DONE**
- 이미지 재적재 후에도 **20,491장 보존** 확인(승격의 `ON DUPLICATE KEY UPDATE`가 `image_url`을 건드리지 않는다)

## 정직한 한계

- **가격은 합성이다.** 순위·비교에는 쓸 수 있지만, 원장·정산의 KRW 금액처럼 다루면 안 된다.
- **재고도 합성이다.** 실제 재고가 아니므로 제약 실험(M4)에서 이 사실을 함께 적는다.
- **이미지는 일부만 있다(19.4%).** Kaggle 인증이 없어 전체를 못 받았다 — 자세한 경로와 커버리지는
  `hm-images.md`에 적었다. 나머지는 화면이 그라디언트로 폴백한다.
- 레거시 데모 상품은 V55에서 은퇴했다. 상품 1~3은 k6·통합 테스트가 써서 남기되, 탐색 표면(카테고리·
  '신상품')에서는 빠지게 했다 — picsum 랜덤 사진을 달고 상품처럼 보이던 것이 스토어프론트를 가짜로 만들었다.
