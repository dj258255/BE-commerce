# S1 — 결합 방식을 서빙 경로에 붙였다: 오프라인과 같고 지연 예산 안이지만, 가상 A/B 에서는 이기지 못했다 (#454)

**서빙 경로는 준비됐고, 가상 사용자 A/B 는 비겼다.** D5 에서 이긴 결합 방식(순위 모델 점수 + GenPage 줄 구성)을 모델 서버 `/page` 에 붙였다.

- 홀드아웃 500명 전원의 페이지가 오프라인 D5 페이지와 상품 순서까지 같았다
- 서버 추론 p95 는 142 ms 로 지연 예산(300 ms) 안이고, 지금 방식(206 ms)보다 빠르다
- 점수가 없는 고객은 지금 방식으로 대체됐고 오류는 0 이었다
- 가상 사용자 5,000명 A/B 에서는 규칙 줄 구성 대비 실제 구매 적중이 +0.0118 이었지만 95% 구간 [−0.0118, +0.0350] 이 0 을 포함했다. 측정 전에 정한 판정 4 에 따라 "가상 A/B 에서도 이겼다"고 적지 않는다

판정 5 의 세 조건 중 지연 · 대체 경로는 충족했고 가상 A/B 는 충족하지 못했다. **ADR-068 의 다시 볼 조건은 아직 충족되지 않았다.** 결합 방식은 "기본값 후보"가 아니라 플래그 뒤 실험군으로 둔다.

- 설계 · 판정: `personalization/docs/genpage-v2/BACKEND.md` "S1" 절(측정 전에 고정, 이력 100건 보정 포함)
- 측정: 2026-10-04 04:21 ~ 04:48, 모델 서버 final `f-base-full-1ep` · CPU · 스레드 2 · 포트 18866
- 재현:
  ```
  PY=<.venv-genpage>/bin/python bash tools/run-s1.sh
  ```
- 원자료: `l1.*` · `l2.*` · `l3.*` · `l4-aa/` · `l4-ab/`, 서버 로그 `server.log`

## L1 서빙 = 오프라인

| compose | 비교 대상 | 일치 |
|---|---|---:|
| `rule` | D3 final B 페이지 | 500/500 |
| `hybrid` | D5 final H-thin-4 페이지 | 500/500 |
| `hybrid-cached` | D5 final H-thin-4 페이지 | 500/500 |

행 토큰과 상품 순서까지 모두 같았다. 측정 전 보정대로 요청 이벤트는 100건을 보냈다. 60건만 보내면 홀드아웃 고객의 32.6% 가 다시 사기 행 이력이 달라 오프라인과 어긋난다.

- 판정 2: `hybrid` 동시성 1 서버 추론 p95 142 ms ≤ 300 ms → **충족**. `hybrid-cached` 는 1.2 ms 다
- `hybrid` 가 지금 방식보다 31% 빠르다. 결합 방식은 상품을 순위 모델 순서로 채우고 모델은 줄(행 토큰)만 고른다. 지금 방식은 행마다 앞 2개 상품을 한 칸씩 생성한다
- **동시성 4 에서는 줄을 선다.** 서버는 잠금 하나로 요청을 하나씩 처리하므로 추론 시간은 그대로(142 ms)이고 왕복 p95 만 513 ms 로 늘었다. 처리량 상한은 초당 약 9 페이지다. 앱은 이미 이 상황을 다룬다. 홈 2쪽은 추천 행과 같은 모델 자리를 나눠 쓰고(#271), 자리가 없으면 기다리지 않고 규칙 행으로 물러선다(X6 에서 잼). 결합 방식은 지금 방식보다 처리량이 높아(9.3 대 6.2/s) 같은 부하에서 물러서는 비율이 줄어드는 방향이다(추정, 앱 부하 측정은 S2)
- `hybrid-cached` 는 조회만 하므로 잠금을 잡아도 1 ms 대다. 다만 2쪽처럼 `exclude` 가 붙는 요청에는 쓸 수 없다

## 왜 가상 A/B 에서 구간이 넓었나

- **표본이 작았다.** 사용자 단위로 나눈 비대응 설계라 한쪽 2,500명이고, 실제 구매 적중의 95% 구간 반폭이 약 0.023 이다. D5 오프라인에서 이긴 크기(페이지 적중 +0.003)는 이 반폭의 8분의 1 이다. 이 크기의 차이를 가를 힘이 처음부터 없었다(측정 전에 따져 보지 않은 것이 이번 설계의 빈틈이다)
- **시뮬레이션에서는 짝 설계가 가능하다.** 실제 서비스와 달리 같은 가상 사용자에게 두 정책을 모두 보여 줄 수 있다. 같은 사용자의 차이로 재면 사용자 간 분산이 빠진다. 다음 비교는 짝 설계와, 측정 전 검정력 계산으로 표본을 정한다(후속)
