## 왜 졌나

1. **다시 사기 행을 놓을 수 없었다.** 검증 1만 명 중 상위 200개 안에 이력 상품이 있는 고객은 7,954명이다. 그중 8개 이상이라 다시 사기 행이 허용된 고객은 1,759명뿐이다(이력 상품 수 중앙값 4). B 는 8개 미만 행도 받아 7,391명의 페이지에 다시 사기 행이 있었다. λ 를 키워도 재구매 적중이 0.027 에 머문 이유다
2. **이 규칙은 D3 를 측정하기 전에 정했지만 두 쪽에 다르게 걸렸다.** G 쪽에만 "상위 200개에 8개 이상인 행" 조건이 있었다. 행 점수를 더한 효과(G-row → H(4), 격차 절반)와 규칙 효과를 가르려고 D5(#450)에서 규칙만 B 와 같게 풀어 다시 잰다
3. **GenPage 몫은 새 상품 쪽이다.** 새 상품 적중 +0.0161 은 다시 사기 행 대신 섹션 행을 더 싣는 데서 온다(추정). D3 · C5 에서도 GenPage 가 이긴 곳은 새 상품이었다
