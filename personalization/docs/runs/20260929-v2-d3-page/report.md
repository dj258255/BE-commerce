# D3 — 같은 상품, 줄 구성만 규칙 대 GenPage, 홀드아웃 판정 (#437)

**GenPage 가 졌다.** 순위 모델이 고른 같은 상위 200개로 페이지를 만들고 줄 구성만 바꿨다. 홀드아웃 68,984명에서 페이지 nDCG 는 규칙 줄 구성(B) 0.0564, GenPage 가 행을 고른 G-row 0.0369 였다. 같은 고객 짝 부트스트랩(2,000회) 차이 구간은 **[−0.0205, −0.0186]** 으로 0 보다 아래다. 측정 전에 정한 판정 3 그대로 "졌다"로 적는다.

넷플릭스는 홈 페이지 전체를 놓고 겨뤘으므로 페이지끼리 비교했다. 이 데이터에서는 줄 구성 싸움에서도 규칙이 이겼다.

> 정정(2026-10-04, #460): 처음에는 "넷플릭스 GenPage 가 이긴 상대가 바로 이 형태(순위 모델 점수 + 규칙 줄 구성)였다"고 적었다. 원문을 확인하지 않은 서술이었다. 원문(arXiv 2606.31031)은 GenPage 가 운영 중인 행 · 콘텐츠 후보 집합 안에서 생성했고 비교 상대가 여러 단계의 운영 추천 시스템이었다고 적는다. 넷플릭스의 비교 상대는 행과 콘텐츠 단계마다 후보 생성 · 순위 모델을 둔 운영 시스템이다.

- 설계 · 판정: `personalization/docs/genpage-v2/STATUS.md` "D3" 절(측정 전에 고정)
- 측정: 2026-09-29 22:16 ~ 2026-09-30 05:45

  - 홀드아웃: R final 16분 · 최대 31.3GB, B 25초 · 4.2GB, G-row 조각 8개를 하나씩 5시간 10분 · 조각당 최대 12.4GB
- R final 의 MAP@12 는 0.034557 로 D2 홀드아웃(0.034557, 반복 241)과 같았다. 두 비교가 같은 순위 모델 위에 있다

## 왜 졌나

1. **다시 사기 행을 거의 고르지 않았다.** 재구매 적중이 B 0.0664, G-row 0.0215 다. 이 데이터에서 가장 강한 신호가 "산 것을 다시 산다"다(한 줄짜리 재구매 규칙이 순위 모델 없이 페이지 nDCG 0.0307). B 는 행 점수를 순위 모델 점수로 매기고, 그 모델의 가장 중요한 특징이 고객이 그 상품을 산 횟수다(D2 특징 중요도 16.1%). 그래서 다시 사기 행이 자주 맨 위로 온다. GenPage 는 이 신호를 점수로 받지 않고 학습 페이지의 행 순서에서 배운다(추정, 행별 선택 빈도는 따로 세지 않았다)
2. **상품을 더 많이 담고도 덜 맞혔다.** G-row 페이지는 평균 46개, B 는 29.6개다(B 는 점수 합으로 고르므로 상품이 적은 행도 들어온다). 그래도 페이지 적중은 B 가 높다. 같은 상품 풀에서 행을 고르는 것만으로 점수가 높은 상품을 덜 싣는다는 뜻이다
3. **GenPage 가 이긴 곳은 새 상품이다.** 새 상품 적중 +0.0089(구간 전체가 0 위). 다시 사기 행 대신 섹션 행을 더 싣기 때문으로 본다(추정). 순서를 매기는 지표(페이지 nDCG · MAP@12)에서는 이 이득이 재구매 손실을 메우지 못했다
4. **넷플릭스와 다른 점.** 넷플릭스는 노출 · 반응 로그로 "이 줄을 보여 줬더니 눌렀다/안 눌렀다"를 학습했다. 여기 학습 페이지는 다음 주 구매로 만든 것이라 줄 배치의 반응을 본 적이 없다. 이 조건 차이를 따로 재려고 Taobao 노출 데이터 실험(T1, #438)을 설계했다

## 판정에 쓰지 않은 것

- 넷플릭스의 두 번째 이득(여러 단계를 모델 하나로 합쳐 지연 −20%)은 재지 않았다. 여기의 G 는 순위 모델 위에 GenPage 를 얹은 것이라 단계가 하나 는다. G-row 생성은 홀드아웃에서 페이지당 약 270 ms(조각당 2,170 ~ 2,420초 / 8,623명), B 는 규칙이라 사실상 0 이다
- G-full 은 검증에서 G-row 에 져 홀드아웃에서 재지 않았다
