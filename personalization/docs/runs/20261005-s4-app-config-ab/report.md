# S4 — 앱 구성 그대로의 짝 A/B 에서도 결합 방식이 이겼다, 기본값을 켠다 (#467)

**앱이 실제로 보여 주는 것 기준으로도 결합 방식이 이겼다.** 홀드아웃 구매 고객 68,984명 전원에게 규칙 줄 구성(A)과 결합 방식(B)을 앱 홈 2쪽과 같은 구성(3행 × 8개, 두 쪽, 2쪽에 1쪽 상품 `exclude`)으로 모두 보여 줬다. 주 지표는 앱 화면 조립기가 상품 3개 미만 행을 버린 뒤의 실제 구매 적중이다.

- 주 지표: A 0.1750, B 0.1799, 차이 **+0.0049**, 95% 구간 **[+0.0039, +0.0059]**
- 버리기 전 실제 구매 적중도 +0.0043 [+0.0034, +0.0053] 으로 같은 방향
- 요청 실패 0, 대체 0, 짝에서 뺀 사용자 0
