# D5 — 행 규칙을 같게 하자 GenPage 행 선택이 규칙 줄 구성을 이겼다 (#450)

**GenPage 가 이겼다.** 같은 상품(순위 모델 상위 200개) · 같은 행 규칙에서 행을 고르는 방식만 달리했다. 홀드아웃 68,984명에서 페이지 nDCG 는 다음과 같았다.

- 규칙 줄 구성(B) 0.0564
- GenPage 행 선택 + 순위 모델 행 점수(H'(4)) 0.0575

같은 고객 짝 부트스트랩(2,000회) 차이 구간은 **[+0.0009, +0.0013]** 으로 0 보다 위다. 측정 전에 정한 판정 3 그대로 "규칙을 같게 하면 GenPage 행 선택이 이겼다"로 적는다.

상대 크기는 +2.0% 다. 페이지 적중 · 새 상품 적중 · 행 적중도 모두 이겼고, 앞 12개로 잰 MAP@12 는 비겼다.

이 비교는 넷플릭스 GenPage 가 이긴 형태와 같다. 순위 모델이 점수를 내고, 그 위에서 무엇을 몇 번째 줄에 놓을지를 GenPage 가 정한다.

- 설계 · 판정: `personalization/docs/genpage-v2/STATUS.md` "D5" 절(측정 전에 고정)
- B 와 순위 모델 점수는 D3 의 것을 그대로 썼다(`personalization/docs/runs/20260929-v2-d3-page/final/B-1.json.gz`)
- 측정: 2026-10-01 11:50 ~ 22:05
  - 검증(1만 명): 두 변형, 각 조각 2개 병렬로 변형당 33 ~ 37분, 조각당 최대 9.4GB
  - 홀드아웃: H'(4) 조각 8개를 하나씩 6시간 12분(조각당 44 ~ 51분), 조각당 최대 12.1GB
  - 검증은 13:00 에 끝났지만 홀드아웃은 15:53 에 시작했다. 정기 확인이 그 사이 처리되지 않아 대기가 생겼다
- 재현:

## 무엇을 바꿨나

D3 · D4 에서 G 쪽에는 "상위 200개에 상품이 8개 이상인 행만 허용" 규칙이 있었고 B 에는 없었다. D5 는 이 규칙을 B 와 같게 했다.

- 허용 행 = 상위 200개에 상품이 1개 이상인 행(B 가 고를 수 있는 행과 같은 집합)
- 행 안 = 그 행의 상위 200개 상품을 점수 순으로 최대 8개. 모자라면 짧은 행으로 둔다(B 와 같다)
- 다른 것은 행을 고르는 방식 하나다
  - B: 행 점수(그 행의 상위 8개 점수 합)가 큰 순서
  - G-row': GenPage 가 고른다
  - H'(4): GenPage 행 로그 확률 + 4 × z(행 점수). λ=4 는 D4 검증에서 고른 값을 그대로 썼다

모델이 행을 채우지 못하게 따로 막았다. 상위 200개 마스크만으로는 이력 상품이 섹션 행 채우기로 새어 들어갔다(구현 중 단위 테스트로 재현). 큰 λ 에서 H' 가 B 와 행 · 순서 · 상품까지 같아지는 것을 확인했다.

## D3 → D4 → D5 에서 알게 된 것

| | 무엇을 바꿨나 | 홀드아웃 페이지 nDCG(GenPage 쪽 − B) |
|---|---|---|
| D3 | GenPage 가 행을 고름(8개 이상 행만) | −0.0195 |
| D4 | + 순위 모델 행 점수 | −0.0097 |
| D5 | + 행 규칙을 B 와 같게 | **+0.0011** |

1. **D3 의 패배에는 두 원인이 있었다.** 하나는 G 쪽에만 걸린 "8개 이상" 규칙이다. 다른 하나는 GenPage 자신의 선택이다. 규칙을 풀어도 GenPage 혼자서는 다시 사기 행을 1만 명 중 879명에게만 올렸다(B 7,391명)
2. **순위 모델 점수가 GenPage 의 약점을 메웠다.** 행 점수를 더하자 다시 사기 행이 B 수준으로 올라왔다. 그 위에서 GenPage 의 몫(새 상품 적중 +0.0031, 행 적중 +0.0016)이 더해져 B 를 넘었다
3. **이긴 형태는 넷플릭스와 같다.** 순위 모델이 무엇이 중요한지를 알려 주고, 생성 모델이 줄의 구성을 정한다. GenPage 혼자(G-row')는 졌다
4. **D3 의 규칙은 측정 전에 정했지만 두 쪽에 다르게 걸렸다.** 측정 전에 정하는 것만으로는 공정하지 않다. 두 변형이 같은 후보 공간에서 경쟁하는지까지 확인해야 했다

## 판정에 쓰지 않은 것

- G-row' 는 검증에서 져 홀드아웃에서 재지 않았다
- 넷플릭스의 두 번째 이득(지연)은 재지 않았다. H' 는 순위 모델 위에 GenPage 를 얹은 것이라 단계가 하나 는다. 생성은 페이지당 약 320 ms(홀드아웃 조각 생성 시간 / 고객 수)다
