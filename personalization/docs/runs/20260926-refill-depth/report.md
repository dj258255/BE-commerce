# 홈 되채우기 깊이 1~4 와 인기 창 all_time (#344)

[ADR-045](../../../../docs/adr/ADR-045-real-popularity-and-refill.md)는 되채우기 깊이 2 를 기본으로 정하면서 "깊이 2가 측정된 유일한 값이다",
"`all_time` 은 재지 않았다"고 적었다. [M7c](../20260921-m7c-인기신호와-되채우기/report.md)와 같은 하네스 · 조건으로 깊이 1~4 와 all_time 을 쟀다.
판정 기준은 [이슈 #344](https://github.com/dj258255/BE-commerce/issues/344)에 **측정 전에** 적었다.

- **2배에 닿는 깊이는 없었다**(최대 1.48배). 깊이 3 이 2 보다 화면 항목을 **+11.0%** 늘려 규칙(10% 이상)을 넘었다. **기본값을 3 으로 올린다**
- 깊이 4 는 3 과 같다. 인기 행이 항목 상한 8 에 닿았다
- 늘어난 몫은 전부 인기 행에서 왔고, 그 대가로 인기 행 안의 평균 순위가 약 3위에서 9위로 내려갔다
- all_time 은 화면 채움 · 순위가 ±10% 안이라 화면으로는 고를 수 없었다. recent_7d 를 유지한다

## 조건

규칙 FULL · 사용자 6명 · 활동 8건 · 행 상한 5 · 항목 상한 8 · 최소 항목 3 · 대분류 상한 3 · 인기 AUTO. 조건마다 3회(응답 18개).
일회용 MySQL(공유 DB 의 카탈로그 · 인기 표 복사본, 창마다 200행) · Redis. 하네스가 활동 상품을 읽는 DB 를 `MYSQL` 로 바꿀 수 있게 했다.

비교(`tools/home_ab_report.py`): 깊이 2 → 3 항목 +1.7개(**+11.0%**) · 순위 1.20배, 3 → 4 항목 −0.2개(−1.0%) · 0.99배,
recent_7d → all_time(깊이 2) 항목 +1.2개(+7.8%) · 순위 0.94배. 잔차는 26.6~28.4ms 로 조건 사이 차이가 폭보다 작았다.

## 예측과 비교

- 예측: 깊이 3 · 4 는 인기 행이 7개 안팎에서 멈춰 화면 항목이 깊이 2 대비 +5% 안팎. **틀렸다.** 인기 행이 깊이 2 에서 6.1개였던 것이 3 에서 7.7개로 한 번 더 크게 늘어 +11.0% 가 됐다. 멈춘 것은 깊이 4 였다
- 순위가 1.3~1.4배에서 2배에 닿지 않는다: 맞았다(1.48배)
- 모델 행 · 최근 행은 깊이와 무관: 맞았다
- all_time 은 항목 수가 비슷하다: 맞았다(+7.8%). all_time 에서 모델 행 항목이 3.8~4.0 에서 4.5~4.7 로 조금 늘었다. 인기 행에 뜨는 상품이 달라져 모델 행과 겹쳐 빠지는 몫이 줄어든 것으로 보지만 재지 않았다

## 판정

1. 평균 표시 순위가 깊이 1 의 2배를 넘는 깊이는 없다
2. 깊이 3 이 2 보다 항목 +11.0%(≥10%) · 기준 1 통과. **기본값 3 을 제안하고 이 PR 에서 올린다.** 문턱을 1.0%p 넘었고 폭이 겹친다는 것을 같이 적는다
3. all_time 은 ±10% 안이라 화면 채움으로 창을 고를 수 없다. recent_7d 유지

## 이 표가 말하지 않는 것

- 품질은 모른다. 인기 행이 9위 상품까지 내려가는 것이 사용자에게 나은지는 온라인 A/B 의 몫이다(ADR-045 대가 절과 같다)
- 인기 표가 창마다 200행이고 항목 상한이 8 이라 나온 값이다. 항목 상한을 바꾸면 멈추는 깊이도 바뀐다
- 모델 행의 되채우기는 코드 설계가 필요해 이번 범위 밖이다

## 재현

```bash
./gradlew -p commerce bootJar
for i in 1 2 3; do for d in 1 2 3 4; do
  OUT_DIR=$R/refill$d-r$i POPULARITY=AUTO REFILL_DEPTH=$d RULES_LEVELS=FULL USERS=6 bash tools/run-home-composition.sh
done; APP_RECOMMENDATION_POPULARITY_WINDOW=all_time OUT_DIR=$R/alltime2-r$i POPULARITY=AUTO REFILL_DEPTH=2 RULES_LEVELS=FULL USERS=6 \
  bash tools/run-home-composition.sh; done
python3 tools/home_ab_report.py "D2=$R/refill2-r1" "D2=$R/refill2-r2" "D2=$R/refill2-r3" "D3=$R/refill3-r1" "D3=$R/refill3-r2" "D3=$R/refill3-r3"
```

원자료: [`raw/`](raw/) (실행마다 요약 표 · 사용자별 홈 응답 · 같은 맥의 CPU, 일회용 DB 로 돌린 러너 `run.sh`)
