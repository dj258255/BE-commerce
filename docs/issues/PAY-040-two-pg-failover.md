# PAY-040 — 두 PG failover 계약 테스트

## 목적

다중 PG가 실제로 복원력을 주는지, 아니면 중복 승인·환불·대사 책임을 늘리는지 검증한다.

## 완료 조건

- UNKNOWN 승인 결과는 다른 PG로 재승인하지 않는다.
- 최초 provider를 보존하고 환불·취소가 같은 계약 경계를 따른다.
- provider transaction/reference와 내부 payment를 대사할 수 있다.

## 예상

- 예상 시간: 1~2일(합성 데이터)
- 결과물: provider 계약표, 상태 머신, 실패 전환 테스트
- 위험: 실 PG 계정·토큰·환불·정산 계약 없이는 통합 완료가 아니다.
