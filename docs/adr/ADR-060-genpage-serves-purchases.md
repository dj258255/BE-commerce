# ADR-060. GenPage 추천 행은 구매 이력으로 서빙하고, 재구매 우선 혼합을 A/B 후보로 둔다

- 상태: **채택**(경로). 기본값은 그대로 `model.kind=stub` · `history-source=activity` · `repeat-first=false`. 켜는 것은 A/B 뒤다
- 날짜: 2026-09-24
- 관련: `PurchaseHistoryFacts`, `RecommendationService`, `ModelRequestBody`, `genpage_server.py`,
  [리포트](../../personalization/docs/runs/hm-genpage-report.md), [ADR-053](ADR-053-genpage-mini-not-default.md), [ADR-054](ADR-054-genpage-validation-tuning.md), 이슈 #254

## 맥락

GenPage 모델은 구매 시퀀스로 학습했고 서빙은 조회·클릭을 넣었다(ADR-053 의 결함). 오프라인에서 선을 넘은 혼합(재구매 우선 + 모델)도
서빙 입력에 구매 이력이 없어 후보가 못 됐다(ADR-054). ADR-054 의 다시 볼 조건이 "주문 모듈이 최근 구매를 내주는 경로가 생기면 혼합을
서빙 경로로 다시 잰다"였다.

## 판정 기준 (이슈 #254 에 측정 전에 적었다)

1. 서빙 모델 단독 MAP@12 가 같은 5,000명의 오프라인 값과 상대 ±5% 안
2. 서빙 혼합이 같은 5,000명의 재구매 규칙 이상이면 A/B 후보. 기본값은 A/B 전에 바꾸지 않는다
3. 서빙 응답은 전부 모델에서(폴백 0)

## 결과 (대입)

| | 모델 단독 | 재구매 규칙 | 혼합 |
|---|---:|---:|---:|
| 오프라인(같은 엔진을 직접) | 0.023295 | 0.025775 | 0.026373 |
| 서빙(앱 경로, 고친 뒤) | 0.023295(1.0000배) | — | 0.026373(규칙의 1.023배) |

폴백 0, p95 20ms. 셋 다 통과.

## 결정

- 주문 모듈이 결제 완료 주문의 상품을 최근 것부터 내준다(`PurchaseHistoryFacts`). 추천은 설정으로 입력을 고른다
- 혼합은 오프라인과 **같은 규칙**(최근 산 것을 중복 없이 먼저, 빈칸을 모델로)으로 서빙에 넣는다. 활동 이력에서는 켜지지 않는다 — 본 것을 산 것처럼 앞에 두지 않는다
- **기본값은 바꾸지 않는다.** 오프라인 +2.3% 는 A/B 로 확인할 후보다(실사용자 판정은 트러블슈팅 기록 열린 항목 5)
- 모델 서버 요청은 길이가 붙은 바이트로 보낸다. 서버는 `history` 가 없는 요청을 400 으로 거절한다

## 이 작업에서 찾은 결함

**#238 부터 GenPage 추천 행은 모든 사용자를 이력 없는 사용자로 생성했다.** `RestClient` 에 Map 을 주면 `Transfer-Encoding: chunked` 로
나가고, 모델 서버(파이썬 표준 HTTP 서버)는 `Content-Length` 만 읽어 빈 본문으로 봤다. 서버는 `history` 가 없으면 빈 목록으로 처리했다.
첫 서빙 채점에서 모델 단독 0.000504(오프라인의 2%)가 나와 알았다. ADR-053 의 홈 2쪽 측정도 이 상태였고, 다시 잰 값으로 리포트를 고쳤다
(p95 k=2 94 → 100ms, 항목 685 → 720, 규칙 위반은 그대로 0).

**목으로 짠 단위 테스트는 이 결함을 볼 수 없었다.** 본문 객체는 맞았고, 틀린 것은 전선 위의 모양이었다. 그래서 실제 HTTP 서버로 받는
테스트(`GenPageClientWireTest`)를 더했다.

## 대가 (정직하게)

- 평가 사용자의 구매는 H&M 거래를 주문 표에 심은 것이다. 실사용자의 구매 이력이 아니다
- 홈 다음 쪽(`/page`)은 여전히 세션의 조회·클릭을 넣는다. 그 경로의 입력 차이는 남았다(ADR-066 에서 구매로 맞췄다)
- 추천 요청마다 주문 표를 한 번 읽는다(`(user_id, id)` 인덱스, 최근 100건)

## 다시 볼 조건

- A/B 결과가 나오면 → 혼합을 켤지 정한다
- 홈 다음 쪽을 모델로 켜려면 → 그 경로의 입력도 구매로 맞추거나, 조회·클릭으로 다시 학습한다
