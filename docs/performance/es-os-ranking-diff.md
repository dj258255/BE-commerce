# ES 와 OpenSearch 의 검색 순서가 25% 다르던 이유 (#262)

두 엔진의 점수는 같았고, **동점을 엔진 안의 문서 순서대로 줄 세운 것**이 전부였다. 그 순서는 색인 절차(적재 중 세그먼트가 언제 생기고 어떻게
병합됐는가)가 정한다. 동점을 상품 id 로 끊자 일부러 순서가 갈리게 색인한 두 엔진의 상위 10개가 545개 쿼리 모두에서 같아졌다(겹침 0.912 → 1.000).
판정 기준은 [이슈 #262](https://github.com/dj258255/BE-commerce/issues/262)에 **측정 전에** 적었다. 결정은 [ADR-064](../adr/ADR-064-engine-tie-break.md).

ADR-051 은 두 엔진의 상위 10개 겹침이 0.753 이라고 적고 "원인은 확인하지 못했다"고 남겼다.

## 방법

- 엔진은 **하나씩** 띄운다(힙 512MB). 둘을 1GB 로 같이 띄웠다가 도커 VM 메모리가 모자라 MySQL 컨테이너가 OOM 으로 멈췄다(되살렸고 데이터는 그대로였다)
- 같은 카탈로그를 색인하고 #236 쿼리 545개를 같은 본문(`EngineQuery.textQuery`)으로 보내 상위 50개와 점수를 받는다
- 상위 10개가 다른 쿼리를 가른다: **동점만 다름**(두 엔진의 합집합 문서 점수가 상대 오차 1e-5 안에서 같다) · **점수 다름** ·
  **상위 50개 밖**(다른 엔진의 상위 10개가 이쪽 상위 50개 안에 없다 — 이때는 상위 10개의 점수 열이 같은지로 동점인지 본다)

## 결과

| 색인 절차 | 정렬 | 겹침 | 같음 | 동점만 다름 | 상위 50개 밖(점수 열 같음) | 점수 다름 |
|---|---|---:|---:|---:|---:|---:|
| 지금(#244 이후: 적재 중 refresh 끔) | 점수 | **1.000** | 545 | 0 | 0 | 0 |
| #236 때(적재 중 refresh 1초) | 점수 | **0.799** | 348 | 127 | 70(70) | 0 |
| #236 때 + 상품 id 필드 | 점수 | 0.912 | 390 | 147 | 6 | 2 |
| #236 때 + 상품 id 필드 | **점수 · 상품 id** | **1.000** | 545 | 0 | 0 | 0 |

- **0.753 이 재현됐다(0.799).** 같은 매핑·같은 질의라도, 적재 중 1초마다 refresh 가 돌면 세그먼트가 엔진마다 다르게 생기고, 하나로 병합한 뒤의
  문서 순서도 달라진다. 동점은 그 순서를 따른다
- **다른 쿼리의 거의 전부가 동점이었다.** #236 절차에서 197개 모두(상위 50개 밖 70개도 상위 10개 점수 열이 두 엔진에서 같았다). 10위 자리의
  동점 무리가 상위 50개 중 중앙값 45개로 크다 — 이름이 같은 상품이 색상별로 여럿이라서다
- **지금 1.000 이 나온 것은 우연이다.** #244 에서 규모 실험 때문에 적재 중 refresh 를 껐고, 그게 두 엔진의 문서 순서를 맞춰 놓았다. 색인을
  다시 만들거나 CDC 로 문서를 갈아 끼우면 다시 갈라질 수 있다(#258 에서 Lucene 이 그랬다)
- **판정 기준(과반이 동점이면 동점 정렬, 겹침 0.95 이상이면 채택)**: 동점 정렬 뒤 1.000. 채택

### 점수가 달랐던 한 쿼리

`flip flop`·`flip flops`(같은 쿼리의 어형) 두 개에서 합집합 문서의 점수가 실제로 달랐다(5.8%). explain 트리에서 처음 갈리는 항은 상품명 필드의
`flip` 단어 boost 였다(7.70 대 3.85, 정확히 두 배). 그런데 **같은 엔진도 색인을 다시 만들 때마다 이 쿼리의 점수가 바뀌었다**
(ES 134.99 → 142.77, OpenSearch 142.77 → 138.89). 엔진 버전 차이가 아니라 색인마다 달라지는 무엇이다. 원인은 확인하지 못했다.
동점 정렬 뒤에는 이 쿼리의 상위 10개도 두 엔진에서 같았다.

## 재현

```bash
# 엔진을 하나씩: 띄우기 → 색인(옛 절차는 --live-refresh) → 수집 → 지우기
python3 tools/search/search_index.py http://localhost:9200 --live-refresh
python3 tools/search/engine_diff.py collect OUT http://localhost:9200 es --sort
python3 tools/search/engine_diff.py classify OUT es os
```

`git show 15268fe:tools/search/products-index.json`.
